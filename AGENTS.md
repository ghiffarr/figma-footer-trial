# Project Goal
Turn the Figma footer design into a real React + Vite website.

## Current Trial
Implement only the Footer section from the Figma reference.

## Rules
- Read the Figma reference before coding.
- Work only on the requested section.
- Do not create unrelated sections.
- Do not edit unrelated files.
- Do not use or reference the old Jaynes/Lovable project.
- Keep the project simple and clean.
- After editing, summarize exactly what changed.

## Allowed Files for This Trial
Cursor may create or edit:
- `src/components/Footer.tsx`
- `src/App.tsx`
- `src/App.css` or `src/index.css` only if needed for styling

Cursor should not create:
- Header
- Hero
- JaynesWay
- Legacies
- Communities
- Innovation
- Southwest
- Any old homepage sections

## Design Requirements
- Match the Figma footer design across desktop, tablet, and mobile.
- Use responsive layout.
- Use the correct text, spacing, colors, and column structure from Figma.
- If the logo/image asset is missing, use a clear text placeholder and mention that the image needs to be exported from Figma.

## Testing
- Run `npm run dev`
- Check desktop, tablet, and mobile responsiveness.
- Make sure there is no horizontal overflow.
